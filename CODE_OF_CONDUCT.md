# Codigo de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/). Resumen:

- Trata a todos con respeto, sin importar experiencia, origen, genero, edad, creencias o aspecto.
- Critica el codigo, no a las personas. Acepta la critica con calma.
- No se tolera el acoso, los insultos, el spam ni la publicacion de datos privados de otros.
- Los mantenedores pueden editar o borrar comentarios, issues y PR, y bloquear a quien incumpla.

Para reportar una conducta inaceptable, escribe un aviso privado en
https://github.com/MesaRestrepo/aprende-de-videos/security/advisories/new
indicando que es de conducta. Se trata con confidencialidad.
